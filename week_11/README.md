# Week 11 - Computer Lab Access System

## Description

This Python program checks whether a student is allowed to enter the computer laboratory.

The system checks:
- Student registration
- Laboratory opening status
- Computer availability

The student is only granted access when all three conditions are satisfied.

## Files

- `main.py` - Main program that connects all modules
- `student.py` - Gets student information and input
- `access.py` - Checks access conditions and provides the reason
- `display.py` - Displays the final result
